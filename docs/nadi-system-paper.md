# Compute-constrained multidialectal Arabic ASR with diversity-aware system combination

Adding more recognizers to an ASR ensemble does not always improve its output. During our work on NADI 2026 Subtask 1.1, an ensemble of four distinct models matched or outperformed a larger ensemble that contained several near-duplicate systems. This mattered in our setting because the full system was developed on one NVIDIA RTX 4070 Ti SUPER GPU with 16 GB of memory. We therefore focused on making each training run useful and on combining models that made different errors. Our pipeline uses w2v-BERT 2.0 fine-tuning, a 5-gram language model, and confusion-network voting for eight Arabic dialects. On an 800-utterance holdout set, the strongest single model obtained 46.12% macro word error rate (WER), while the best clean ensemble obtained 42.59%.
